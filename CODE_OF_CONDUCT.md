# Code Of Conduct

## Expected Behavior

- Be direct and useful.
- Critique code and ideas, not people.
- Keep disagreements concrete enough to resolve.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Derailing issues or pull requests with unrelated arguments.
- Publishing private security reports before there is a fix.

## Enforcement

Maintainers may edit, hide, or remove comments and may block contributors who make the project harder to work on. This is a small package, not a debating society.
